RS-Sync — Gitリポジトリ同期ツール

GitHub / open-gitea / Gitea / Gitbucket 間でリポジトリを一方向バックアップ同期・双方向同期します。

ここは管理者向け本番環境です。試しに触ってみたい方はデモ環境をどうぞ: https://easy-web.tokyo/rs-sync/demo
This is the admin/production environment. If you just want to try it out, use the demo instead: https://easy-web.tokyo/rs-sync/demo

クイック設定: マスター→コピー先(複数可)

「このGitHub組織/アカウントをマスターとして、変化があれば以下の組織/ アカウントへ全リポジトリをコピー同期する」という設定を、アカウント登録・ ジョブ作成を個別に行わずまとめて作成します(コピー先は複数指定可)。 一方向(マスター→コピー先のみ)・全リポジトリ・下で選んだ間隔での 自動実行として作成されます。

「リアルタイム」はWebhookではなく1分間隔のポーリングです(サーバーへの 負荷とAPIレート制限にご注意ください)。

アカウント

GitHub・open-gitea・Gitea・Gitbucketいずれかのプロバイダで、同期の ソース(コピー元)または宛先(コピー先)として使うアカウントを登録します。 トークンは同期実行時にサーバー内部でのみ使用し、一覧には表示されません。

⚠️ これはデモ環境で、ログイン無しで誰でも閲覧できます。実際のGitHub トークン等は絶対に入力しないでください。/ This is the demo environment, viewable by anyone without login. Never enter a real GitHub token or other real credentials here.

アカウントを追加

GitHubなら通常そのまま https://api.github.com でOK。open-gitea等は自分でホストしているURL。

GitHubなら通常そのまま https://github.com でOK。git@github.comのようにSSH形式で指定すると、VPS上のSSH鍵を使ったclone/push(トークン不要)になります(ただしリポジトリ一覧取得・新規作成はGitHubの仕様上トークンが必要なままです)。

GitHubならfine-grained personal access token(repoスコープ)。ここに入力した値は一覧に再表示されません。

フォルダ同期(GitHub等とは別、レンタルサーバー・VPS・ローカルドライブ・スマホ・NAS間のファイルコピー)
